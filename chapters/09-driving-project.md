# Chapter 09 — 자율주행 실전 프로젝트

**기간:** 2주 | **전제:** Chapter 07, 08

이 챕터는 지금까지 배운 SLAM·Nav2·센서 융합을 **하나의 시스템으로 합치는** 프로젝트 챕터입니다. TurtleBot3 자율주행 미션을 수행합니다.

## 학습 목표

- SLAM·Nav2·센서 융합을 하나의 시스템으로 통합할 수 있다
- 동적 장애물을 회피하면서 주행할 수 있다
- Multi-waypoint 내비게이션을 구현할 수 있다
- 실제 환경 매핑과 내비게이션을 수행할 수 있다

## 프로젝트 — 자율주행 물류 로봇

Gazebo에 물류 창고 환경을 만들고, TurtleBot3가 물류 미션을 수행하는 시스템을 구현합니다.

### 미션 시나리오

1. 창고 입구에서 출발
2. A 지점에서 물건(상자)을 인식하고 픽업 위치로 이동
3. B 지점까지 물건을 운반
4. C 지점을 경유해서 출발점으로 복귀
5. 도중에 나타나는 동적 장애물(움직이는 사람·다른 로봇)을 회피

### 구현 요소

- **지도 생성:** SLAM으로 창고 지도를 미리 만든다
- **내비게이션:** Nav2로 Multi-waypoint 경로를 설정한다
- **센서 융합:** LiDAR + 카메라를 함께 써서 장애물을 인식한다
- **동적 장애물 회피:** Costmap과 로컬 플래너로 움직이는 장애물을 피한다
- **상태 관리:** 미션 단계를 상태머신으로 관리한다 (출발 → 픽업 → 운반 → 복귀)

### 평가 기준

- [ ] 4개 웨이포인트를 모두 순서대로 방문한다
- [ ] 동적 장애물에 충돌하지 않고 회피한다
- [ ] 전체 미션을 5분 이내에 완료한다
- [ ] 미션 수행 과정을 RViz 영상으로 기록한다

## AI 활용법

- "Multi-waypoint 내비게이션을 Nav2로 어떻게 구현해? 순서대로 목표를 주는 패턴을 알려줘"처럼 구현 패턴을 물어봅니다.
- "상태머신으로 미션을 관리한다는 게 무슨 뜻이야? 간단한 예시 코드를 보여줘"처럼 설계 패턴을 물어봅니다.
- "동적 장애물이 있을 때 Nav2가 어떻게 회피하는 거야? Costmap이랑 로컬 플래너 역할을 설명해줘"처럼 동작 원리를 물어봅니다.
- 미션이 실패하면 "어느 웨이포인트에서 막혔고, 로그는 이래"라고 구체적으로 상황을 알려주고 원인을 물어봅니다.
