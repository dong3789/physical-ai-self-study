# Chapter 08 — 로봇 AI 심화: VLM·VLA·강화학습

**기간:** 2주 | **전제:** Chapter 03, 06, 07

이 챕터의 목표는 **로봇 AI를 한 단계 깊게** 배우는 것입니다. VLM·VLA 활용과 파인튜닝, 강화학습 기초(PPO·SAC), Reward 설계를 다룹니다.

## 학습 목표

- VLM·VLA 모델을 로봇 작업에 활용할 수 있다
- 파인튜닝의 개념과 절차를 이해한다
- 강화학습의 기본 개념(상태, 행동, 보상, 정책)을 설명할 수 있다
- PPO와 SAC의 차이를 설명할 수 있다
- Reward를 설계할 수 있다
- 시뮬레이션 기반 학습의 흐름을 이해한다

## 학습 내용

### 1주차 — VLM·VLA 활용과 파인튜닝

- **VLM 활용:** 이미지 + 언어 지시를 로봇 작업에 연결하는 방법. 예: "빨간 컵을 집어"라는 지시를 VLM이 해석해서 목표 물체를 찾는 흐름
- **VLA 활용:** VLM 출력을 로봇 행동으로 변환하는 파이프라인
- **파인튜닝 기초:** 사전 학습 모델을 내 작업 데이터로 추가 학습시키는 방법. LoRA 같은 경량 파인튜닝 개념
- **실습:** VLM으로 Gazebo 장면에서 지시한 물체를 찾고, 그 위치를 Chapter 05의 Grasp Pose 추정과 연결한다

### 2주차 — 강화학습 기초

- **강화학습 개념:** 에이전트가 환경과 상호작용하면서 보상을 최대화하는 정책을 배우는 방법
- **MDP:** 상태(State), 행동(Action), 보상(Reward), 정책(Policy)의 정의
- **PPO:** 안정적으로 정책을 업데이트하는 대표적인 알고리즘
- **SAC:** 연속 행동 공간에서 잘 동작하는 오프폴리시 알고리즘
- **Reward 설계:** 보상을 어떻게 설계하느냐가 학습 성패를 가른다. Sparse Reward vs Dense Reward, Reward Shaping
- **시뮬레이션 기반 학습:** 왜 실제 로봇이 아니라 시뮬레이션에서 강화학습을 하는지 (속도, 안전, 리셋 용이성)
- **실습:** Gymnasium 환경에서 간단한 강화학습(예: CartPole)을 PPO로 학습시켜보고, Reward를 바꿨을 때 학습이 어떻게 달라지는지 확인한다

## 실습 과제

### 과제 1 — VLM + Grasp 연결

"파란 상자를 집어"라는 언어 지시를 VLM으로 해석해서 목표 물체를 찾고, Chapter 05에서 만든 Grasp Pose 추정을 이용해 로봇팔이 실제로 집는 동작까지 연결합니다. 언어 지시를 바꾸면 다른 물체를 집는지 확인합니다.

### 과제 2 — CartPole PPO 학습

Gymnasium의 CartPole 환경에서 PPO로 정책을 학습시킵니다. 학습 곡선을 그리고, 에피소드 보상이 어떻게 변하는지 관찰합니다. Reward를 일부러 잘못 설계해보고 학습이 망가지는 것을 확인한 뒤, 원래대로 돌려서 비교합니다.

### 과제 3 — 로봇 시뮬레이션 강화학습 (개념)

Gazebo TurtleBot3가 목표 지점까지 가는 작업을 강화학습으로 푼다고 가정하고, 상태·행동·보상을 어떻게 정의할지 설계 문서로 작성합니다. 실제로 학습을 돌리는 것은 무겁기 때문에, 설계와 Reward 함수 구현까지만 합니다. GPU가 있으면 간단한 버전으로 학습을 시도해봅니다.

## AI 활용법

- "PPO랑 SAC 차이가 뭐야? 언제 어떤 걸 써?"처럼 비교 질문을 합니다.
- "Reward 설계가 왜 중요해? 잘못 설계하면 어떤 일이 생겨?"처럼 실전 함정을 물어봅니다.
- "LoRA 파인튜닝이 뭐야? 전체 파인튜닝이랑 뭐가 달라?"처럼 효율화 기법을 물어봅니다.
- "내 PPO 학습이 안 돼. 보상 곡선이 이래. 뭐가 문제일까?"처럼 학습 곡선과 함께 물어봅니다.
