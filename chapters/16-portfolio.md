# Chapter 16 — 포트폴리오와 취업 준비

**기간:** 2주 | **전제:** Chapter 15

이 챕터의 목표는 지금까지 만든 것을 **취업용 포트폴리오로 정리**하는 것입니다. 이력서, 포트폴리오, 면접 대비를 준비합니다.

## 학습 목표

- 프로젝트를 포트폴리오로 정리할 수 있다
- 이력서에 Physical AI 경험을 효과적으로 쓸 수 있다
- 면접에서 프로젝트를 설명할 수 있다
- 지원할 기업과 직무를 정할 수 있다

## 진행 내용

### 1주차 — 포트폴리오 정리

- **프로젝트 선별:** Chapter 09(자율주행 물류 로봇), Chapter 15(최종 프로젝트)를 중심으로 2~3개를 고른다
- **각 프로젝트 문서화:** 문제 → 접근 → 구현 → 결과 → 배운 점의 구조로 정리한다. 수치(성공률, 수행 시간)를 포함한다
- **GitHub 정리:** 각 프로젝트 저장소의 README를 다듬는다. 시연 영상 링크를 넣는다
- **포트폴리오 페이지:** GitHub 프로필 README나 개인 페이지에 프로젝트를 정리한다

### 2주차 — 이력서와 면접 준비

- **이력서 작성:** 백엔드 경력 + Physical AI 학습·프로젝트를 연결해서 쓴다. "백엔드 개발자가 로봇 AI로 확장했다"는 서사가 핵심이다
- **예상 면접 질문 준비:** 아래 질문에 답을 준비한다
  - "ROS2에서 Topic과 Service의 차이는?"
  - "SLAM이 무엇인지 설명해주세요"
  - "Sim-to-Real Gap을 어떻게 해결했나요?"
  - "VLA 모델에 대해 설명해주세요"
  - "백엔드 경험이 로봇 개발에 어떻게 도움이 되나요?"
- **모의 면접:** AI와 모의 면접을 한다. AI에게 면접관 역할을 맡기고, 프로젝트 설명을 연습한다
- **지원 기업 정리:** 로봇·자율주행·스마트 팩토리 관련 기업을 조사하고, 지원할 곳을 정한다

## 실습 과제

### 과제 1 — 포트폴리오 페이지

GitHub 프로필 README 또는 개인 페이지에 포트폴리오를 정리합니다. 각 프로젝트마다 한 문단씩, 문제·접근·결과·링크를 포함합니다.

### 과제 2 — 이력서 초안

이력서 초안을 작성합니다. 백엔드 경력과 Physical AI 프로젝트를 한 문서에 담습니다. AI에게 "이 이력서를 로봇 엔지니어 채용 담당자 입장에서 리뷰해줘"라고 요청해서 피드백을 받습니다.

### 과제 3 — 모의 면접 3회

AI와 모의 면접을 3회 진행합니다. 매번 다른 질문을 받고, 답변을 녹음하거나 글로 정리해서 개선합니다. 특히 프로젝트 설명을 1분 안에 끝내는 연습을 합니다.

## AI 활용법

- "이 프로젝트를 면접에서 1분 안에 설명하는 스크립트를 짜줘"라고 요청합니다.
- "로봇 엔지니어 면접에서 자주 나오는 질문 10개를 뽑아줘"라고 요청합니다.
- "내 이력서를 보고, 로봇 엔지니어 채용 담당자가 궁금해할 점을 짚어줘"라고 피드백을 받습니다.
- 모의 면접은 "너는 로봇 회사 면접관이야. 내 최종 프로젝트에 대해 꼬리질문을 해줘"라고 시작합니다.
