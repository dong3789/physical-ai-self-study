# Physical AI 독학 커리큘럼 — AI와 함께 배우는 로봇 엔지니어 로드맵

KANT 피지컬 AI 로봇 엔지니어 부트캠프(9개월, 1,516시간) 커리큘럼을 기반으로 만든 **AI와 함께하는 독학용** 로드맵입니다. 부트캠프에 가지 않고, AI를 튜터 삼아 직접 배우는 사람을 위한 것입니다.

- **대상:** 프로그래밍 경험이 있는 개발자 (특히 백엔드 개발자). Python 기초가 있으면 더 빠르게 갑니다.
- **방식:** 챕터별로 배우고, 각 챕터 끝에 직접 만드는 실습 프로젝트로 마무리합니다.
- **환경:** Mac(Apple Silicon)에서도 대부분 가능합니다. 단, Isaac Sim은 NVIDIA GPU가 필요하므로 해당 챕터는 Gazebo 대안으로 진행합니다. (게이밍 PC나 클라우드 GPU가 있으면 Isaac Sim으로 진행하세요.)
- **소요:** 챕터당 1~3주, 전체 약 37주(8~9개월, 주 10~15시간 기준). 속도는 자기 페이스에 맞게 조절하세요.

## AI와 함께 배우는 법

이 커리큘럼은 AI를 **튜터**로 쓰는 것을 전제로 합니다. 각 챕터마다 "AI 활용법"이 적혀 있습니다. 공통 원칙은 다음과 같습니다.

1. **개념은 AI에게 설명을 요청하되, 직접 손으로 확인합니다.** "ROS2 Topic이 뭐야?"라고 묻고, 답을 들은 뒤 직접 노드를 짜서 돌려봅니다. 코드만 받고 이해하지 않으면 남는 게 없습니다.
2. **에러는 그대로 붙여넣습니다.** 에러 메시지 + 내가 한 일을 함께 주면 AI가 원인을 짚어줍니다. "안 돼"가 아니라 "이 명령을 쳤더니 이 에러가 났어"라고 구체적으로 말합니다.
3. **구현은 AI와 페어로 합니다.** "이 기능을 구현하고 싶은데, 먼저 설계를 같이 짜보자"라고 시작합니다. AI가 짠 코드를 그대로 쓰지 말고, 한 줄씩 읽고 이해한 뒤에 씁니다.
4. **매 챕터 끝에는 AI 없이 복습합니다.** 챕터의 핵심 개념을 AI 도움 없이 자기 말로 정리해봅니다. 설명할 수 없으면 아직 모르는 것입니다.
5. **막히면 범위를 좁혀서 질문합니다.** "SLAM이 안 돼"가 아니라 "Gazebo에서 TurtleBot3로 SLAM을 돌렸는데 맵이 안 그려져. 이 로그가 나와"처럼 좁혀서 묻습니다.

## 환경

- **OS:** Ubuntu 22.04 (ROS2 Humble 기준). Mac에서는 Docker로 Ubuntu 컨테이너를 띄워서 진행합니다. 네이티브 macOS에서 ROS2를 직접 설치하는 것은 권장하지 않습니다.
- **필수:** Docker, VS Code, Git, Python 3.10+
- **시뮬레이터:** Gazebo (기본), RViz (시각화)
- **선택:** NVIDIA GPU가 있는 PC 또는 클라우드 GPU (Isaac Sim을 쓸 때만 필요)
- **실물 로봇 (없어도 됨):** TurtleBot3, Jetson Orin NX, LiDAR, RGB-D 카메라가 있으면 좋지만, 없어도 시뮬레이션으로 전 과정을 진행할 수 있습니다. 실물이 생기면 Sim-to-Real 챕터에서 연결합니다.

자세한 환경 설정은 [Chapter 00](chapters/00-setup.md)을 보세요.

## 원본 커리큘럼과의 차이

- **Isaac Sim → Gazebo 대안:** Mac(Apple Silicon)에서는 Isaac Sim이 안 돌아갑니다. 12~14챕터는 Gazebo 기반으로 진행하고, GPU가 생기면 Isaac Sim으로 갈아탈 수 있게 구조를 잡았습니다.
- **기업 연계 프로젝트 → 자기주도 최종 프로젝트:** 실제 기업 과제는 없으므로, 15챕터에서 스스로 문제를 정의하고 Physical AI 시스템을 만듭니다. 포트폴리오용으로 충분한 규모입니다.
- **PLC·SCADA 실습 → 개념 + 시뮬레이션:** 산업용 하드웨어가 없으므로 개념과 OPC UA 시뮬레이션으로 진행합니다.
- **속도:** 부트캠프는 풀타임 9개월이지만, 이 로드맵은 주 10~15시간을 가정한 37주입니다. 풀타임으로 하면 더 빨리 끝낼 수 있습니다.
